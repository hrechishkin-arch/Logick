# Logick

Личный сайт для планирования развоза по Киеву и Киевской области.
Заявки из 1С → машины до 1.5 т → маршрут по районам → правка руками → список точек водителю.

Данные хранятся только в браузере этого компьютера.

## Как открыть

1. Создайте репозиторий `logick` на GitHub (Public).
2. Залейте файлы этой папки в корень репозитория.
3. Settings → Pages → branch `main` → folder `/ (root)`.
4. Сайт: `https://hrechishkin-arch.github.io/logick/`

Пока можно просто открыть `index.html` двойным щелчком.
